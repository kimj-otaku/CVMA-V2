# แผนการดำเนินงาน: ปรับระบบสู่การใช้งานจริง (Production-Ready) & ระบบแนะนำการใช้งานใหม่ทีละหน้า (Interactive Onboarding Tour)

เอกสารนี้ได้รับการปรับปรุงเพื่อมุ่งเน้นการใช้งานได้จริงในระดับโปรดักชัน (Real Production Readiness) โดยจะกำจัดข้อมูลและเครื่องมือจำลองทั้งหมด (Mock Data & Test Simulators) ออกจากโค้ด พร้อมทั้งติดตั้งระบบแนะนำการใช้งานใหม่แบบ Interactive Tour ทีละขั้นตอนในทุกหน้าของแอปพลิเคชันอย่างเป็นระบบ

---

## สรุปการตัดสินใจและข้อกำหนดสำคัญ (Critical Decisions & Scope)

> [!IMPORTANT]
> **การปรับปรุงสู่ระบบใช้งานจริง 100%**:
> 1. **การลบข้อมูลจำลองทั้งหมด**:
>    - นำส่วน DOM `🧪 โหมดทดสอบ Streak Rewards` และปุ่มจำลอง Streak ทั้งหมดออกจาก `progress.html`
>    - ลบฟังก์ชันจำลอง `simulateStreak()`, `resetSimulatedStreak()` และตัวแปร Storage จำลองที่ไม่จำเป็นออก
>    - ทำความสะอาด LocalStorage คีย์ประวัติการเรียนจำลอง (`cvma_study_history`, `cvma_daily_words_*`, `cvma_streak_*`) ให้รีเซ็ตสู่สถานะเริ่มต้น 0 คำ 0 วัน เหมือนผู้ใช้ใหม่เพิ่งเริ่มใช้งาน
>    - รักษาคลังคำศัพท์ HSK 1 และระบบ Spaced Repetition (SRS) มาตรฐานไว้อย่างสมบูรณ์
> 2. **ระบบแนะนำผู้ใช้งานใหม่แบบหน้าต่อหน้า (Interactive Onboarding Tour)**:
>    - ติดตั้งระบบ Tour Modal อัจฉริยะที่แสดงอัตโนมัติเฉพาะการเข้าใช้งานหน้าแรกในแต่ละหน้า (First-time Visit)
>    - ติดตั้งปุ่ม `💡 วิธีใช้งาน` (Help / Tour Trigger) บน Header ของทั้ง 6 หน้า เพื่อให้ผู้ใช้สามารถกดเปิดอ่านคำแนะนำซ้ำได้ทุกเวลา
>    - ออกแบบ UI ทัวร์ให้สวยงาม สไตล์พาสเทลมินิมอล สะอาดตา ไร้ความรก (Anti-Slop) พร้อมปุ่ม `ถัดไป`, `ย้อนกลับ`, `ข้าม`, และตัวบอกลำดับขั้นตอน (Step Dots)

## 1. รายละเอียดการทำงานของระบบ Onboarding Tour รายหน้า (Page-by-Page Specifications)

ระบบจะรองรับการแนะนำทีละขั้นตอนอย่างละเอียดในทั้ง 6 หน้า:

### หน้าที่ 1: หน้าหลักแดชบอร์ด (`index.html`)
- **Step 1: เป้าหมายคำศัพท์ประจำวัน (Daily Goal)** — อธิบายการตั้งเป้าหมายคำศัพท์ เช่น 10 คำต่อวัน และความสำคัญของความสม่ำเสมอ
- **Step 2: การแจ้งเตือนเตือนใจรายวัน (Daily Reminder)** — แนะนำการตั้งเวลาเตือนความจำอัตโนมัติหากยังไม่ครบเป้าหมายในแต่ละวัน
- **Step 3: กราฟสถิติความต่อเนื่อง 7 วัน (Streak Chart)** — แสดงแนวโน้มการสะสมคำศัพท์และรักษาวินัยการเรียนรู้
- **Step 4: ทางลัดเริ่มบทเรียน & ทบทวนด่วน** — จุดเริ่มต้นเข้าสู่บทเรียนปัจจุบันและการทบทวนคำศัพท์ที่ถึงกำหนด

### หน้าที่ 2: หน้ารวมบทเรียน (`chapters.html`)
- **Step 1: คลังบทเรียน HSK 1** — เลือกศึกษาบทเรียนตามหมวดหมู่คำศัพท์ที่จัดเรียงไว้เป็นหมวดหมู่
- **Step 2: หลอดวัดระดับความจำ (Mastery Progress)** — ดูสถิติคำที่จำได้แม่นแล้วและคำที่กำลังเรียนรู้ในแต่ละบท
- **Step 3: สร้างบทเรียนและเพิ่มคำศัพท์เอง (+ บทเรียนใหม่)** — แนะนำฟังก์ชันการเพิ่มคำศัพท์และสร้างบทเรียนส่วนตัว

### หน้าที่ 3: หน้าเรียนรู้คำศัพท์ (`learn.html`)
- **Step 1: แฟลชการ์ดคำศัพท์อัจฉริยะ** — แตะการ์ดเพื่อพลิกดูความหมาย ตัวอย่างประโยค และแตะลำโพงเพื่อฟังการออกเสียงภาษาจีนที่ถูกต้อง
- **Step 2: ระบบประเมินความจำ Spaced Repetition (SRS)** — ปุ่มประเมิน 3 ระดับ (จำไม่ได้, พอจำได้, จำได้แม่น) ซึ่งจะคำนวณวันทบทวนรอบถัดไปให้อัตโนมัติ
- **Step 3: เครื่องมือช่วยเรียน (Audio Autoplay & Pinyin Toggle)** — ปรับแต่งการแสดงพินอินและการเล่นเสียงอัตโนมัติเพื่อความสะดวก

### หน้าที่ 4: หน้าทบทวนด่วน (`quick-review.html`)
- **Step 1: ทบทวนคำศัพท์ที่ถึงกำหนด (Due for Review)** — ระบบจะดึงเฉพาะคำศัพท์ที่ถึงเวลาทบทวนตามอัลกอริทึมสมอง Spaced Repetition
- **Step 2: เทคนิคการทบทวนอย่างมีประสิทธิภาพ** — แนะนำการทบทวนสั้นๆ 5 นาทีทุกวันเพื่อเปลี่ยนความจำระยะสั้นเป็นความจำระยะยาว

### หน้าที่ 5: หน้าแบบทดสอบ (`quiz.html`)
- **Step 1: โหมดเลือกตอบและพิมพ์ตอบ** — ทดสอบความแม่นยำของพินอินและความหมายภาษาไทย
- **Step 2: โหมดพูดออกเสียง (Speak to Answer)** — ฝึกออกเสียงจริงผ่านไมโครโฟน โดยระบบตรวจจับเสียงจะวิเคราะห์ความถูกต้องให้อัตโนมัติ
- **Step 3: การประเมินผลคะแนน** — สรุปคะแนนการทดสอบและอัปเดตสถิติความจำเข้าระบบทันที

### หน้าที่ 6: หน้าสรุปความคืบหน้า (`progress.html`)
- **Step 1: ภาพรวมคลังคำศัพท์และระดับความจำ** — แผนภูมิแสดงจำนวนคำศัพท์ทั้งหมดแยกตามระดับความจำ (SRS Level 0 - 5)
- **Step 2: รางวัลเหรียญเกียรติยศ Streak (7 วัน & 30 วัน)** — สะสมความต่อเนื่องเพื่อปลดล็อกเหรียญ ⚡ มุ่งมั่น 7 วัน และ 👑 ปรมาจารย์ 30 วัน พร้อมพลุ Confetti
- **Step 3: ปฏิทินประวัติการเรียน (Study Heatmap)** — บันทึกวันที่เข้าเรียนจริงในแต่ละวัน

## 2. การออกแบบ UI และประสบการณ์ผู้ใช้ (UI & Visual Design)

- **โทนสีและบรรยากาศ (Color Palette)**:
  - พื้นหลังการ์ดทัวร์: สีขาวนวลตัดกับขอบพาสเทลซากุระ `#FFE4EC`
  - ไอคอนและสัญลักษณ์: โทนซากุระแดงอมชมพู `#D9385C` และทองคำ `#B45309`
  - ปุ่มนำทาง: ปุ่มหลักสีสดใสไล่เฉดซากุระ (`linear-gradient(135deg, #FF7597, #FF5A82)`), ปุ่มย้อนกลับและข้ามสีโทนนุ่มนวล
- **การจัดวาง (Spatial Placement)**:
  - Modal กลางหน้าจอพร้อม Backdrop มัวแบบ Glassmorphism (`backdrop-filter: blur(4px)`)
  - มีตัวบอกลำดับขั้นตอนแบบจุดวงกลม (Step Indicator Dots)
  - รองรับหน้าจอทุกขนาด ตั้งแต่มือถือ (Mobile Touch) ไปจนถึงคอมพิวเตอร์ Desktop (1440px)
- **ปุ่มเปิดดูซ้ำ (Permanent Help Button)**:
  - เพิ่มปุ่ม `💡 วิธีใช้งาน` หรือ `❓ แนะนำหน้านี้` ใน Header ของทุกหน้า ให้ผู้ใช้สามารถแตะเพื่อเปิดทัวร์หน้านั้นๆ ได้ตลอดเวลา

## 3. สถาปัตยกรรมข้อมูลและแผนการเชื่อมโยง (Data Architecture)

```
┌─────────────────────────────────────────────────────────────┐
│                    Onboarding Tour Engine                   │
│   (Shared Logic in app.js: initPageTour, showTourModal)     │
└──────────────┬───────────────────────────────┬──────────────┘
               │                               │
       ┌───────▼────────┐             ┌────────▼───────┐
       │ First-Time Auto│             │  Manual Replay │
       │ (LocalStorage) │             │  (Header Btn)  │
       └───────┬────────┘             └────────┬───────┘
               │                               │
               └───────────────┬───────────────┘
                               │
               ┌───────────────▼───────────────┐
               │    Tour Modal Component UI    │
               │  - Step Indicator (1/4, 2/4)  │
               │  - Icon & Feature Headline    │
               │  - Detailed Instructions      │
               │  - Prev / Next / Close State  │
               └───────────────────────────────┘
```

- **LocalStorage Keys สำหรับเก็บสถานะทัวร์**:
  - `cvma_tour_seen_home`
  - `cvma_tour_seen_chapters`
  - `cvma_tour_seen_learn`
  - `cvma_tour_seen_review`
  - `cvma_tour_seen_quiz`
  - `cvma_tour_seen_progress`
- **การรีเซ็ตข้อมูลจำลอง (Clean Reset)**:
  - ฟังก์ชัน `cleanSimulatedData()` จะล้างคีย์การทดสอบทั้งหมด และเซ็ตค่าเริ่มต้นของสถิติวันแรกให้เป็น 0

## 4. ขั้นตอนการลงมือปฏิบัติงาน (Execution Plan)

1. **ขั้นตอนที่ 1: ลบเครื่องมือและข้อมูลจำลองทั้งหมด**
   - ตัดโค้ด `.streak-simulator-box` ออกจาก `progress.html`
   - ลบฟังก์ชัน `simulateStreak` และ `resetSimulatedStreak` ออกจาก `app.js`
   - รีเซ็ตสถิติการเรียนและประวัติจำลองให้เป็นศูนย์เริ่มต้น
2. **ขั้นตอนที่ 2: เพิ่มสไตล์ CSS สำหรับ Onboarding Tour**
   - สไตล์สำหรับ Backdrop, Tour Modal, Step Indicators, และปุ่ม Help ใน Header
3. **ขั้นตอนที่ 3: ติดตั้งปุ่ม Help และเชื่อมต่อ Tour ในแต่ละหน้า HTML**
   - ติดตั้งปุ่ม `💡 วิธีใช้งาน` ใน `index.html`, `chapters.html`, `learn.html`, `quick-review.html`, `quiz.html`, และ `progress.html`
4. **ขั้นตอนที่ 4: พัฒนาระบบขับเคลื่อน Onboarding Tour ใน `app.js`**
   - สร้างอาร์เรย์คำแนะนำของแต่ละหน้า (6 หน้า)
   - ฟังก์ชันตรวจสอบการเข้าใช้งานครั้งแรก (Auto-trigger on first visit)
   - Event Handler สำหรับปุ่ม Next, Prev, Skip, และ Replay
5. **ขั้นตอนที่ 5: ตรวจสอบและคอมไพล์ระบบ (Verification)**
   - ทดสอบเปิดทัวร์และตรวจสอบการทำงานในทุกหน้า
   - รันคำสั่ง `compile_applet` เพื่อยืนยันว่าโปรเจกต์คอมไพล์ผ่าน 100%
